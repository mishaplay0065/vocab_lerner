# Vocab — Telegram Mini App для изучения слов

Мобильное приложение для изучения слов и фраз на разных языках по
CSV-словарям, с карточками разных типов и интервальным повторением (spaced
repetition). Интерфейс на русском языке. Работает без регистрации.

Прогресс синхронизируется между устройствами через `Telegram.WebApp.CloudStorage`,
когда приложение открыто внутри Telegram; при локальном тестировании в обычном
браузере (или если CloudStorage недоступен) автоматически используется
`localStorage` — в шапке приложения всегда видно, какой режим сейчас активен.
Поддерживается несколько независимых наборов слов (например, «English A1» и
«German Verbs») с переключателем в шапке. Наборы группируются по языкам, а
режим «Все наборы · Английский» (и аналогичные для других языков) позволяет
учить и повторять наборы одного языка в одной сессии, не смешивая языки.

## Хранилище и синхронизация между устройствами

`storage.js` устроен в два слоя:

1. **Бэкенд** — низкоуровневые `getItem`/`setItem`/`getItems`/`removeItems`.
   При запуске внутри Telegram и доступном `Telegram.WebApp.CloudStorage`
   используется он (данные привязаны к пользователю Telegram и видны на
   всех его устройствах в том же боте и аккаунте). Вне Telegram используется
   `localStorage` (данные остаются только в этом браузере/устройстве).
   Если при запуске из Telegram облако недоступно, показывается ошибка,
   а не пустое локальное хранилище. Активный бэкенд
   показан в шапке приложения.
2. **`VocabStore`** — то, с чем работает `app.js`: список наборов, активный
   набор, настройки, загрузка/сохранение слов конкретного набора.

CloudStorage от Telegram имеет жёсткие ограничения (Bot API 6.9+): не более
1024 ключей, ключ — 1–128 символов из `[A-Za-z0-9_-]`, **значение — не более
4096 символов**. Один набор слов легко превышает 4096 символов в JSON, поэтому
JSON набора разбивается на части до 3500 символов (ключи
`s_<idВерсии>_<номерЧасти>`). Индекс наборов тоже разбивается на части.
Изменения текста и состава пишутся в новую версию, затем переключается указатель, и только
после подтверждения удаляется предыдущая версия. Старый формат наборов
читается без повторного импорта. Обычный ответ записывает небольшой блок прогресса
(до 8 слов), отдельно для каждого устройства, без повторной отправки контекстов
и текстов. При загрузке выбирается последнее сохранение слова. Если блок
слишком велик или не хватает запаса ключей, используется безопасная запись
целого набора. Редактирование включает накопленный прогресс в новую версию.

Операции записи выполняются по очереди. Ошибка не считается успехом;
несохранённые ответы резервируются в этом браузере и повторяются в фоне после
запуска, при возвращении в приложение и восстановлении сети.
Если недоступно и локальное хранилище, приложение предупреждает не закрывать
страницу. Потерянное подтверждение небольшой записи проверяется чтением.
Если неопределён результат переключения целого набора, нужна перезагрузка;
кнопка в уведомлении перезагружает, а не повторяет заблокированный запрос.
Одновременное структурное изменение словаря на разных устройствах не защищено
серверной транзакцией — Telegram CloudStorage не используется здесь как
транзакционная база. Данные Telegram и Safari остаются раздельными.

История занятий хранится в помесячных записях `act_<device>_<YYYYMM>`.
Счётчики разных устройств суммируются, повторная отправка одного счётчика
объединяется по максимуму. Старый снимок не затирает историю другого устройства.
Сохранившаяся старая серия переносится как базовая история; дни, восстановленные
из счётчика, помечаются без выдуманного числа ответов. Серия сохраняется
независимо от записи слов. Есть локальная резервная копия истории для каждого
режима хранения и аккаунта Telegram. Историю, которая не сохранилась ни в
облаке, ни в резервной копии, восстановить автоматически невозможно.

Telegram SDK загружается асинхронно. Главная не загружает содержимое
одноязычных наборов: слова читаются при открытии занятия, повторения или прогресса.
Сохранение не блокирует главную, версионированные ресурсы берутся из кэша.

Незавершённое занятие восстанавливается в том же браузере. Кнопка «Новое
занятие» позволяет заменить очередь после подтверждения без сброса прогресса слов.

Файлы не используют сборщики и модули — это обычные `<script>`-теги в
`index.html`, поэтому проект можно открыть напрямую и разместить как
статические файлы на любом HTTPS-хостинге (GitHub Pages, Netlify, Vercel,
Cloudflare Pages и т. д.).

## Как это работает (кратко)

- **Главная** — ежедневная цель и наборы слов. Новые наборы показаны выше старых,
  дата добавления сохраняется. Короткий свайп влево открывает «Удалить», длинный
  свайп вызывает окно подтверждения. Без подтверждения набор не удаляется.
  Можно выбрать один набор или объединение всех наборов одного языка.
  На главной есть блок «По языкам», а в переключателе повторения и прогресса —
  «Все наборы · Английский», «Все наборы · Немецкий» и т. п. Прогресс сохраняется
  в исходных наборах. Смешанные англо-немецкие наборы разделяются по словам
  автоматически; для других языков нужно явно указать язык набора при импорте.
  Выбранный язык запоминается после перезапуска приложения.
- **Импорт** — при добавлении набора пользователь называет его, выбирает язык и загружает
  один CSV-файл (`term;translation;context`, поддерживается и запятая) или
  нажимает «Загрузить демо-набор».
  Есть список распространённых языков и поле для своего варианта.
- **Учить — Study → Test.** Слово, которое встречается впервые, сначала
  показывается как карточка для изучения (термин, перевод, контекст,
  кнопка «Я запомнил» — без проверки), и сразу же вслед за этим на то же
  самое слово даётся проверочное упражнение (выбор перевода или ввод
  ответа). Именно результат этой проверки — первая реальная попытка,
  которая идёт в интервальное повторение. Слова, которые уже повторяются
  (не новые), сразу получают упражнение без экрана изучения — среди них
  вперемешку встречаются выбор из 4 вариантов, ввод ответа,
  орфография/сборка слова, флеш-карта и изредка мини-игра «найди пару».
  В упражнении с пропущенными буквами каждый пропуск — отдельное поле;
  ввод переходит к следующему, Backspace возвращает к предыдущему.
- **Повторение** — кнопка «Повторить сейчас» выбирает новые и незакреплённые слова,
  а примерно одно место из пяти оставляет для изученных, которые не повторялись
  хотя бы сутки. Если незакреплённых мало, свободные места заполняются изученными.
  Для любых слов без ожидания доступна свободная практика.
  Выбранное количество слов не ограничивается десятью:
  знакомое слово получает одну проверку, новое/сложное — дополнительные;
  общий подход рассчитан примерно на 20 заданий даже при выборе 16 слов.
  Если выбрать больше 20 слов, минимум одно задание на слово всё же остаётся.
  По умолчанию предлагается короткий подход из 5 слов; просроченные слова и
  недавние ошибки получают приоритет, а часть места сохраняется для новых слов.
  Сверху видны общий прогресс и число заданий; ответ учитывается сразу после
  проверки, до нажатия «Далее» и завершения занятия.
  Также доступны вкладки «К повторению»,
  «Сложные», «Изученные» и «Давно не видел». Ползунок «Сколько слов повторить»
  движется плавно, а количество слов остаётся целым числом.
- **Попытки и проверка** — в заданиях с вводом, выбором и сборкой доступны три
  попытки. Первые две ошибки не раскрывают ответ; третья показывает правильный
  вариант и отмечает слово как сложное. Пропущенные буквы и сборка проверяются
  точно; в свободном вводе английское начальное `to` необязательно, а
  возможная опечатка предлагает исправление без
  потери попытки, но не даёт автоматического зачёта.
  Если свободный перевод тоже верен, но отсутствует в наборе, уже после первой
  попытки можно явно засчитать его и сохранить как дополнительный вариант.
  Для английского предусмотрены проверенные пары британского и американского
  написания (например, `demoralized` / `demoralised`); похожие, но разные
  слова автоматически не приравниваются.
  Артикли и заглавные буквы немецких существительных по-прежнему обязательны.
- **Выученные слова** — иногда появляются для контрольного повторения, с отдыхом
  хотя бы сутки после последнего ответа. После ошибки дополнительная практика
  доступна через 10 минут. Заработанные правильные ответы не отнимаются.
- **Карточки** — в разделе повторения можно пролистывать термины и открывать
  перевод нажатием на карточку. Этот режим не меняет прогресс слов.
- **Ежедневная цель** — ответы за текущий день показываются на главной.
  Цель на 5, 10 или 20 ответов выбирается в разделе «Прогресс»; счётчик
  сбрасывается на следующий день и сохраняется вместе со стриком.
- **Календарь серии** — на главной видна текущая неделя. Нажатие на серию
  открывает месяц с днями занятий, текущей/лучшей серией и числом активных дней.
  Можно посмотреть прошлые месяцы и число ответов за конкретный день.
  Используется местная дата устройства; будущие дни не выбираются.
- **Оформление** — спокойная сине-голубая палитра в светлой и тёмной темах,
  однотонный фон без декоративного свечения, локальный шрифт Inter и текстовая
  нижняя навигация. У выпадающих списков скрыты системные стрелки, а текст
  выровнен по центру высоты.
  Полоса прокрутки скрыта, сама прокрутка работает.
  Единые лёгкие поверхности, мягкая плавающая навигация и облегчённые карточки
  оформлены без фоновых изображений и постоянных тяжёлых эффектов.
  Liquid glass заметен в плавающем меню, переключателях и диалогах: прозрачность,
  размытие и световые края. Выбранная вкладка перемещается внутри стеклянной капсулы.
  Учебные карточки остаются плотными, без размытия текста. При повышенном контрасте
  или уменьшении прозрачности используются непрозрачные поверхности; движение
  отключается при соответствующей настройке системы. Новых библиотек и запросов нет.
- **Проверка ответа** — пустой ответ считается ошибкой; варианты русского
  перевода через запятую и правильный перевод с другим порядком слов принимаются.
- **Прогресс** — каждый правильный ответ добавляет одну единицу к счётчику слова.
  Пять правильных ответов дают статус «Изучено», в том числе за один день.
  Три правильных задания на слово за занятие дают 3/5, ещё два — 5/5.
  Шкала ограничена пятью, но полная статистика верных ответов продолжает расти.
  Ошибки не уменьшают счётчик: они помечают слово для дополнительной практики.
  Подход не требует ждать между ответами. План не добавляет лишние задания
  сверх оставшихся до пяти правильных ответов.
- Общий процент равен сумме прогресса слов, делённой на число слов × 5.
  Каждый результат сохраняется сразу. При обновлении до модели 4 учитываются
  все ранее сохранённые правильные ответы; прежний заработанный прогресс
  не теряется, даже если история ответов неполная.
- При открытии приложения сперва показывается экран загрузки, пока данные
  не будут получены из CloudStorage/localStorage — это исключает ложное
  сообщение «На сегодня всё», которое могло бы появиться, если попытаться
  построить очередь до того, как слова реально загружены.

## Как протестировать локально

Открыть `index.html` двойным щелчком (`file://`) можно для простой проверки
интерфейса, но установка на экран Домой и офлайн-кэш в этом режиме не работают.
Функции Telegram доступны только внутри Telegram.

Рекомендуемый способ — поднять локальный сервер из папки проекта:

```bash
cd vocab_lerner
python3 -m http.server 8080
# или: npx serve .
```

Затем открыть `http://localhost:8080` в браузере (лучше всего — в
мобильном режиме разработчика, ширина экрана ~375–414px).

Проверить сохранение, восстановление занятия, импорт, ответы, ежедневную цель
и стрик можно командой `node --test tests/*.test.js` или `node tests/deep-audit.cjs`.
Добавлены регрессионные тесты; подробности и ограничения проверки устройств
описаны в `QA_REPORT_2026-10-29.md`; актуальные правила прогресса и их проверка —
в `QA_PROGRESS_2026-10-29.md`. Проверка в изолированном браузере:
`PLAYWRIGHT_MODULE=/path/to/playwright node tests/browser-smoke.cjs`.

Проверочный сценарий:
1. Нажать «Загрузить демо-набор» (или загрузить свой CSV / `sample.csv`).
2. На главной открыть набор и пройти несколько карточек — ответить и верно, и
   неверно, чтобы увидеть обратную связь.
3. Добавить второй набор: он должен оказаться выше первого даже после перезагрузки.
4. Смахнуть его влево: сначала появится «Удалить», при длинном свайпе — окно
   подтверждения. Отмена должна вернуть карточку на место.
5. Открыть «Повторение» и «Прогресс» — убедиться, что счётчики обновились.

## Как открыть в Telegram

Мини-приложения Telegram обязательно должны быть размещены по HTTPS —
локальный `http://localhost` Telegram не примет.

1. **Разместите файлы на HTTPS-хостинге**, например GitHub Pages, Netlify,
   Vercel или Cloudflare Pages. Просто загрузите содержимое папки
  `vocab_lerner/` — сборка не нужна. Получите публичный URL, например
  `https://username.github.io/vocab_lerner/`.
2. **Создайте бота**, если его ещё нет: откройте [@BotFather](https://t.me/BotFather)
   в Telegram, отправьте `/newbot` и следуйте инструкциям.
3. **Подключите Mini App**: в диалоге с @BotFather отправьте `/newapp`
   (или `/mybots` → выбрать бота → `Bot Settings` → `Menu Button` /
   `Configure Mini App`) и укажите ваш HTTPS-адрес как URL приложения.
4. **Откройте бота в Telegram** и нажмите кнопку меню (или воспользуйтесь
   отправленной BotFather ссылкой вида `https://t.me/ВашБот/app`) — Mini
   App откроется внутри Telegram, автоматически подхватит тему оформления
   (`Telegram WebApp SDK` уже подключён в `index.html`) и будет работать
   так же, как и в браузере.

В Telegram прогресс хранится в `Telegram.WebApp.CloudStorage` и синхронизируется
между устройствами. При запуске в обычном браузере приложение автоматически
использует `localStorage` текущего браузера.

Входа через Google и ИИ-помощника пока нет: для них требуется отдельный
проект с авторизацией и серверной защитой API, который владелец приложения
ещё не создал. Анонимные данные остаются в текущем хранилище.

## Установка на iPhone через Safari

1. Загрузите на GitHub Pages **все файлы** из папки проекта, включая
   `manifest.webmanifest`, `sw.js` и три PNG-иконки. Открывать локальный файл
   `index.html` через `file://` для установки не нужно: используйте HTTPS-адрес сайта.
2. Откройте этот адрес именно в **Safari** на iPhone.
3. Нажмите «Поделиться» → «На экран „Домой“» (или «Добавить на экран Домой»),
   включите «Открывать как веб-приложение», если такой переключатель показан,
   и нажмите «Добавить».
4. Запускайте Vocab с новой иконки на главном экране. После первого успешного
   открытия онлайн основные файлы приложения доступны без сети.

Версия из Safari хранит слова и прогресс **локально на этом iPhone** и не
подключается к Telegram CloudStorage. Наборы и прогресс из Telegram не
переносятся автоматически. Не удаляйте данные сайта или иконку приложения,
если не сохранили нужные слова отдельно.

## Формат CSV

```
term;translation;context
achieve;достигать;She worked hard to achieve her goals.
die Erfahrung;опыт;Er hat viel Erfahrung in diesem Bereich.
```

- Разделитель — `;` (предпочтительно) или `,`, определяется автоматически
  по первой строке файла.
- Первая строка может быть заголовком (`term`, `translation`, `context` —
  распознаются и русские варианты: `слово`/`термин`, `перевод`, `контекст`/`пример`)
  либо сразу данными в порядке `term;translation;context`.
- Поле `context` необязательно.
- Поддерживаются кавычки вокруг полей (в том числе с разделителем или
  переносом строки внутри) и BOM в начале файла.
- Строки без `term` или `translation` отмечаются как ошибки с указанием
  номера строки; полные дубликаты пропускаются с предупреждением.

Демо-файл с 10 словами лежит в `sample.csv`.
