Загрузи CSV-файл со словами и фразами на английском или немецком — приложение построит для тебя карточки и расписание повторений.

Формат файла

Первая строка может быть заголовком: term;translation;context.

Разделитель — точка с запятой ; (предпочтительно) или запятая ,.

Поле context необязательно. Текст в кавычках поддерживается, файл может быть в UTF-8 (с BOM или без).

Пример строки: run;бежать;He can run fast.
